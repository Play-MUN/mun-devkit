# What the devkit uses

Nothing below is copied into this repository unless the table says so.

| Component | Use | Licence | In the repository |
| --- | --- | --- | --- |
| [MUN OS](https://github.com/Play-MUN/mun-os) card tool and `mun_card` package | Run and imported from a MUN OS checkout to validate and build cards, parse `mun-project.toml`, and apply the save rules in the simulator | Apache-2.0 | No; pinned by `mun-os.lock.json` |
| MUN OS documents (`docs/runtime.md`, `docs/saves.md`, `docs/game-cards.md`) | The contracts the client, the simulator and the checks follow; the simulator repeats the console's stable codes and their sentences | Apache-2.0 | Codes and sentences only |
| Debian 13 "trixie" base image and packages (GCC, glibc, Python, Mesa) | The build environment (`tools/env/Dockerfile`) | Each package's own; Debian main | No; fetched when the environment is built |
| SDL 2 | The sample's window, input and threads; linked dynamically against the console's copy | zlib | No |
| OpenAL Soft | The sample's sound; linked dynamically against the console's copy | LGPL-2.0-or-later | No |
| Mesa | Software rendering of the sample in checks | MIT and others | No |
| e2fsprogs | Used by MUN OS's card tool to build images | GPL-2.0 and others | No |
| Bandit 1.8.6 and pyflakes 3.4.0, and what Bandit imports | Analyse the devkit's own Python (`make analyse`); installed by `make dev-tools` from `tools/dev-requirements.txt`. Not needed to use the devkit or to build a game | Apache-2.0 (Bandit, stevedore), MIT (pyflakes, markdown-it-py, mdurl, rich, PyYAML), BSD-2-Clause (Pygments) | No |
| [Contributor Covenant](https://www.contributor-covenant.org) 2.1, in English and in Spanish | The code of conduct (`CODE_OF_CONDUCT.md`, `CODE_OF_CONDUCT.es.md`), with this project's contact address | CC BY 4.0 | **Yes**, with its attribution |
| [Godot Engine](https://godotengine.org) 4.7.2-stable | Runs the Godot adapter's tests; fetched and verified by `engines/godot/fetch.sh` | MIT; a game that ships it includes its licence text and third-party notices | No |

The sample's sound is generated by `samples/hello-mun/tools/make_blip.py`;
its typeface is the table in `samples/hello-mun/src/draw.c`. No asset comes
from elsewhere.

The devkit's own licences are in [licensing](licensing.md). A game made
with it compiles `client/c/mun.c` into itself under a licence that asks
nothing of the game.
